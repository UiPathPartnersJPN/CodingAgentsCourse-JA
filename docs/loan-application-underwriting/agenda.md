# 学習の進め方

**第2部では、環境を整えたあと、パイプラインを構成する 4 つのコンポーネントをすべて構築・デプロイします。** AI エージェント、ローン担当者用アプリ、それらをつなぐ Maestro フロー、そして全体を駆動する RPA ワークフローです。最後にエンドツーエンドで通して実行します。

## 所要時間の目安

自習なので、**1回で終える必要はありません。** 各レッスンは独立したプロジェクトフォルダーで作業するため、区切りのよいところで中断できます。

| ステップ | 内容 | 目安 | 中断できるか |
| ---: | :--- | ---: | :--- |
| [**コーディングエージェントとは？**](what-is-a-coding-agent.md) | 全体像、ツール、スキル、そして UiPath がどこに位置づくのかを理解する | 15 分 | — |
| [**0. 演習環境を準備する**](0-environment-setup.md) | Orchestrator のフォルダーとストレージバケット、**ソリューション**を作成する | 20 分 | ✅ |
| [**1. AI による与信審査**](1-underwriting-agent.md) | ローン申込をスコアリングする Python のコーデッドエージェントを構築・デプロイする | 70〜90 分 | ✅ |
| [**2. ローン担当者レビュー用ダッシュボード**](2-loan-officer-app.md) | ローン担当者が承認・却下を判断するための React アプリを構築・デプロイする | 55〜75 分 | ✅ |
| [**3. Maestro Flow によるオーケストレーション**](3-maestro-flow.md) | エージェントを呼び出し、リスクバンドに応じて振り分ける Maestro プロセスを構築する | 75〜100 分 | ✅ |
| [**4. 申込受付とデータ補完**](4-intake-enrichment.md) | 申込を送信してフローを起動する Studio の RPA ワークフローを構築する | 65〜85 分 | ⚠️ 実行中は中断不可 |
| [**第2部の完了**](you-did-it.md) | 結果を確認し、次の一歩を確認する | 15 分 | — |

**合計の目安: 5〜7 時間**（コーディングエージェントの生成待ちと LLM の実行時間を含む）

!!! warning "レッスン4 は実行中に中断できません"
    レッスン4 の RPA ワークフローは、起動した Maestro フローの完了を待ちます。中・高リスクの申込では Action Center の人的タスクで停止するため、**実行したらその場で Action Center を開いて承認する必要があります。**

    まとまった時間（30 分程度）が取れるときに着手してください。詳しくはレッスン4 の手順をご覧ください。

## レッスンの依存関係

**順番どおりに進めてください。** 後のレッスンが前のレッスンの成果物を参照します。

```
0. 環境準備
   └─ フォルダー / バケット
        │
        ├─→ 1. コーデッドエージェント  ──┐
        │      出力6項目                  │
        │                                 ├─→ 3. Maestro フロー ──→ 4. RPA ワークフロー
        └─→ 2. ローン担当者アプリ      ──┘       final_decision         results.csv
               入力12項目                                                  ↓
                                                                    ストレージバケット
```

!!! note "成果物はソリューションにまとまります"
    レッスン1・3・4 のプロジェクトは、レッスン0 で作る **1 つのソリューション**の中に作ります。
    レッスン2 のアプリだけは例外でソリューションの外に置きます（理由はレッスン2 で説明します）。

特に重要なのは、**レッスン1 のエージェントが出力する 6 項目**です。

```
credit_score / risk_band / assessment_summary /
monthly_repayment / debt_to_income_ratio / loan_to_market_ratio
```

この 6 項目を、レッスン2 のアプリとレッスン3 のフローがそのまま参照します。**レッスン1 でひとつでも欠けていると、レッスン3 で変数をマッピングできません。** レッスン1 の「生成されたコードを確認する」で必ず確認してください。
