# 第1部 コーディングエージェント入門

**UiPath CLI とスキルをセットアップし、CLI の感触をつかんだうえで、最初のエージェントの構築と公開までをコーディングエージェントから行います。**

## 概要

**コーディングエージェント** は、やり方さえ分かれば、開発者と同じように UiPath の自動化を構築・運用できます。そのために教え込むものは 2 つです。

- **UiPath CLI** — エージェントがプラットフォームとやり取りするためのコマンドラインインターフェイス
- **UiPath スキル** — その CLI を *いつ*・*どのように* 使うのかをエージェントに伝える、キュレーション済みの手順パック

第1部は準備運動にあたります。環境を整え、CLI とスキルでできること・使い方の感触をつかんだうえで、小さなエージェントで **構築と公開のループを 1 周** 通して体験します。コーディングエージェントにエージェントの内容を説明し、スキャフォールドされる様子を見守り、Studio Web に公開して実行する、という流れです。

ここで作るエージェントはあえてシンプルにしてあります。狙いは、**第2部で何度も使うことになるワークフローを身につけること**だからです。

## はじめる前に

事前に自分で準備が必要なのは、**コーディングエージェント**だけです。それ以外は[0. 前提ソフトウェアを準備する](0-prerequisites.md)で導入します。

| 必要なもの | 補足 |
|---|---|
| **コーディングエージェント** | Claude Code、Cursor、GitHub Copilot、Gemini CLI、Codex、OpenCode のいずれか。インストールして**サインインまで済ませておいてください** |
| **LLM のサブスクリプションまたは API キー** | コーディングエージェント側の利用料がかかります |
| **ソフトウェアをインストールできる PC** | インストーラーの実行には通常、管理者権限が必要です |
| **UiPath Cloud アカウント** | **ご自身のテナント**を使用します。演習に使う組織とテナントを決めておいてください |
| **安定したインターネット接続** | 社内規定で必要な場合は VPN も |

!!! note "UiPath CLI とスキルは事前準備が不要です"
    [レッスン1](1-install-the-cli-and-skills.md)でインストールします。先に入れておく必要はありません。

!!! warning "費用について"
    本コースでは、コーディングエージェントと UiPath の両方で LLM を使います。

    - **コーディングエージェント側**（Claude Code など）— お使いのプランに従って課金されます
    - **UiPath 側** — エージェントの実行時に LLM Gateway を経由し、テナントの枠から消費されます

    第2部のレッスン1・3・4 は同じエージェントを複数回実行するため、相応のトークンを消費します。

    **ご自身の UiPath テナント**で進めます。本文中の `{{ org_name }}` と `{{ training_tenant }}` は、

!!! note "生成される内容は毎回変わります"
    コーディングエージェントは LLM を使うため、**生成されるコードやファイル構成は実行のたびに少しずつ変わります。** 本文の出力例とまったく同じものが出るとは限りません。

    各レッスンの確認項目では、**一字一句の一致ではなく、必要な要素が揃っているか**を見てください。
