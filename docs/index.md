# UiPath コーディングエージェント 自習コース

**コーディングエージェントを使って UiPath のエージェントと Maestro オーケストレーションを構築します。ツールのインストールから、長時間実行される自動化をリリースするところまでを一気通貫で学びます。**

!!! tip "演習環境"
    **ご自身の UiPath テナントで進めます。** 演習に使う組織とテナントを決めて、サインインできる状態にしておいてください。

    **第1部は、一般的な開発者向け権限（Automation Developer）だけで完走できます。**
    **第2部に進む前に**、[管理者向け：テナントの事前設定](admin-setup.md)を管理者の方へお渡しください。
    演習用フォルダーの作成とロールの割り当てに、管理者権限が必要です。

## このコースで作るもの

ゼロの状態から、コーディングエージェントを使った実践的な自動化を構築します。まず **`uip` CLI** と **UiPath スキル** をセットアップし、そのうえでエージェントとオーケストレーションを構築していきます。**Claude Code** のようなコーディングエージェントに面倒な作業を任せつつ、主導権はあなたが握り続けるスタイルです。

コースは 2 部構成です。

[**第1部 · コーディングエージェント入門**](getting-started/index.md) — 環境を整え、コーディングエージェントを使うと UiPath コンポーネントの作り方がどう変わるのかを学び、最初のエージェントを構築・公開します。

[**第2部 · ローン審査の自動化**](loan-application-underwriting/index.md) — コードファーストの与信審査パイプラインを丸ごと構築します。Python のコーデッドエージェント、React のコーデッドアプリ、Maestro フロー、そして UiBank のローン申込を審査・振り分ける RPA ワークフローを作ります。

## 自習の進め方

本コースは、講師の同席を前提としない自習用に構成しています。

- **第1部 → 第2部の順に進めてください。** 第2部は第1部で導入した CLI とスキルを前提にしています
- **1回で終える必要はありません。** 各レッスンは独立したプロジェクトフォルダーで作業するため、途中で中断しても再開できます。所要時間の目安は[学習の進め方](loan-application-underwriting/agenda.md)にあります
- **つまずいたら**[トラブルシューティング](troubleshooting.md)を参照してください。詰まりやすい箇所とその確認方法をまとめています
- **ひととおり終えたら**[演習環境の片付け](cleanup.md)で、テナントに残ったリソースを削除できます

!!! warning "LLM の利用料について"
    本コースのエージェントは実行のたびに LLM を呼び出します。**第2部のレッスン1 と レッスン3・4 は、同じエージェントを複数回実行する**ため、相応のトークンを消費します。

    - UiPath の **LLM Gateway** を使う場合（本コースの既定）、消費は UiPath テナントの枠から引かれます
    - コーディングエージェント側（Claude Code など）の利用料は、お使いのプランに従って別途かかります

    実行回数を抑えたい場合は、各レッスンの「動作確認」でテストする件数を減らしてください。

## 主要なコンセプト

- **コーディングエージェント（Coding agent）** — あなたの指示に従って UiPath のコンポーネントを構築する AI アシスタント（例: Claude Code）です。`uip` CLI と UiPath スキルを使って動作します。UiPath は、コーディングエージェントがネイティブに操作できる自動化プラットフォームです。
- **`uip` CLI** — コーディングエージェントが UiPath プラットフォームとやり取りするためのコマンドラインインターフェイスです。
- **UiPath スキル（UiPath skills）** — UiPath の自動化を正しく構築する方法をコーディングエージェントに教える、キュレーション済みの手順パックです。
- **Maestro** — 長時間実行されるプロセス全体にわたって、人・ロボット・AI エージェントを連携させる UiPath のオーケストレーションプラットフォームです。

!!! note "生成される内容は毎回変わります"
    本コースではコーディングエージェントにコードを生成させます。**LLM を使うため、生成されるコードやファイル構成は実行のたびに少しずつ変わります。**

    各レッスンの「生成されたものを確認する」では、**一字一句の一致ではなく、必要な要素が揃っているか**を確認してください。本文に載せている出力例も、そのまま同じものが出るとは限りません。
